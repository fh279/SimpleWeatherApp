# Конспект по корутинам в Kotlin

## Лекция 1. Базовые принципы

**Потоки** — механизм для реализации многозадачности в программе.

**Корутины** — инструмент для асинхронных операций, не выполняющихся параллельно.

**Асинхронность** — возможность приостанавливать выполнение задачи. При множестве задач каждая запускается по очереди.

**Continuation** — механизм управления работой корутин, похожий на callback.

### Основные отличия корутин от потоков:

* Корутины работают значительно быстрее потоков.
* Не требуют новых системных ресурсов, используют заданный системный пул.
* Поток блокируется во время ожидания, корутина — нет.
* Возможность получения данных из БД или с сервера.
* Привязка к жизненному циклу (например, открытие/закрытие экрана).

### Ключевые понятия:

* **Диспатчер** — определяет потоки выполнения.
* **Корутин билдер** — инструмент создания корутин.
* **Корутин скоуп** — определяет жизненный цикл.
* **Deferred** — используется для вывода результата работы корутины.

## Лекция 2. CoroutineContext. Настройка корутин

### Основные элементы контекста корутин:

1. **Job** — задача, выполняемая в фоне.
   * Состояния: new, active, completing, canceling, canceled, completed.
   * Родительские и дочерние джобы.
   * Методы: cancel, invokeOnCompletion, join, start, children, ensureActive.

2. **Dispatcher** — выбирает потоки выполнения.
   * Default — стандартный диспатчер.
   * IO — для IO-операций.
   * Main — для главного потока.
   * Unconfined — не привязан к потоку.

3. **CoroutineExceptionHandler** — механизм перехвата ошибок.

4. **CoroutineName** — задает имя корутины для отладки.

## Лекция 3. Жизненный цикл корутины. Structured concurrency

**Structured concurrency** — механизм, предоставляющий иерархию корутин.

### Принципы работы CoroutineScope:

* Отмена выполнения дочерних корутин при ошибке.
* Хранение корутин как детей в джобе.
* Автоматическое ожидание выполнения дочерних корутин.

## Лекция 4. Обработка ошибок

### Способы обработки ошибок:

* try-catch.
* CoroutineExceptionHandler.
* launch и async.

## Лекция 5. Каналы

**Каналы (Channel)** — механизм передачи значений между корутинами.

### Основные методы:

* send — отправка значения.
* receive — получение значения.
* trySend, tryReceive — работа без suspend-функций.
